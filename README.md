# Caption AI - Yahia Balash — حوّل الفيديو إلى نص

أداة عربية بصفحة واحدة: أدخل رابط فيديو أو ارفع ملفاً، فتحصل على النص الكامل لتعديله ونسخه وتحميله (TXT / SRT) ومشاركته.

## بنية الملفات

```
caption-ai/
├── index.html          ← الصفحة الوحيدة (الواجهة)
├── style.css           ← التصميم
├── script.js           ← منطق الواجهة (بدون أي مفاتيح API)
├── manifest.webmanifest← بيانات تطبيق الهاتف (PWA) ومشاركة الروابط إليه
├── sw.js               ← عامل الخدمة: التثبيت كتطبيق وفتح الواجهة بسرعة
├── asr-worker.js       ← تفريغ الكلام على الجهاز نفسه (Whisper في المتصفح)
├── icons/              ← أيقونات التطبيق
├── README.md
└── server/
    ├── app.py          ← خادم Flask: جلب الترجمات + تفريغ الكلام
    ├── requirements.txt
    └── .env.example    ← انسخه باسم .env وضع مفتاحك فيه
```

## ما الذي يعمل في المتصفح وما الذي يحتاج الخادم؟

| الوظيفة | أين تعمل |
|---|---|
| التحقق من الرابط، اختيار الملف، المعاينة، العدّاد، تكبير الخط | المتصفح |
| التعديل، النسخ، التنسيق، الاستعادة، تحميل TXT/SRT، المشاركة | المتصفح |
| جلب الترجمة الرسمية/التلقائية من الرابط | الخادم (yt-dlp) — **مجاني** |
| تنزيل صوت الفيديو من الرابط واستخراج الصوت من الملف | الخادم (yt-dlp + ffmpeg) — **مجاني** |
| تحويل الكلام إلى نص (Speech-to-Text) | الخادم ← Groq أو OpenAI (**مفتاح API**) أو Whisper محلي (**مجاني**) |

**لماذا الخادم ضروري؟** المتصفح لا يستطيع قراءة ترجمات YouTube أو صوت فيديو من موقع آخر (سياسة CORS)، ولا يجوز وضع مفتاح API سري في JavaScript، واستخراج الصوت يحتاج إلى ffmpeg.

## التشغيل محلياً خطوة بخطوة

1. ثبّت Python 3.10 أو أحدث.
2. ثبّت المكتبات:
   ```bash
   pip install -r server/requirements.txt
   ```
   (تتضمن `imageio-ffmpeg` التي توفّر ffmpeg تلقائياً، فلا تحتاج لتثبيته يدوياً.)
3. أنشئ ملف الإعدادات:
   ```bash
   copy server\.env.example server\.env
   ```
   (على macOS/Linux: `cp server/.env.example server/.env`)
4. افتح `server/.env` وضع مفتاحك، مثلاً `GROQ_API_KEY=gsk_...` (انظر القسم التالي).
5. شغّل الخادم:
   ```bash
   python server/app.py
   ```
6. افتح المتصفح على **http://localhost:5000**

مؤشر الحالة أعلى الصفحة يبيّن: 🟢 جاهز بالكامل، 🟡 متصل لكن تفريغ الصوت غير مُعدّ (تعمل الترجمات الموجودة فقط)، 🔴 الخادم غير مُشغَّل.

> بدون أي مفتاح يعمل الموقع فعلياً مع روابط الفيديوهات التي لها ترجمة منشورة (أغلب فيديوهات YouTube)، ويعرض رسالة صريحة عند الحاجة إلى تفريغ الصوت.

## الوضع المستقل: الهاتف وحده دون حاسوب (GitHub Pages)

عند فتح الموقع من **GitHub Pages** (أو عندما يكون الحاسوب غير متاح) ينتقل تلقائياً إلى **الوضع المستقل**:

| | الوضع المستقل (الهاتف وحده) | مع خادم الحاسوب |
|---|---|---|
| ملف فيديو من الهاتف | ✅ يُفرَّغ على الهاتف نفسه عبر Whisper | ✅ يُفرَّغ على الحاسوب |
| رابط YouTube / Facebook | ❌ يحتاج الخادم (المتصفح يمنع جلب الفيديو من موقع آخر) | ✅ |
| الإنترنت | فقط في أول مرة لتنزيل النموذج، ثم يعمل دون اتصال | — |
| الخصوصية | لا يغادر الصوت هاتفك | يبقى على حاسوبك |

**نماذج التفريغ على الجهاز** (تُختار من «نموذج التفريغ على هذا الجهاز»، وتُنزَّل مرة واحدة):
- **Base** (≈ 80 إلى 145 ميغابايت): الأسرع، دقة أقل في العربية.
- **Small** (≈ 250 إلى 300 ميغابايت): متوازن، الافتراضي عند توفر WebGPU.
- **Large v3 Turbo** (≈ 760 ميغابايت): الأدق للعربية، للهواتف القوية مع WebGPU (مثل Galaxy S24).

يستخدم معالج الرسوميات (WebGPU) تلقائياً في Chrome على أندرويد عند توفره، وإلا المعالج العادي (أبطأ).

**مشاركة فيديو من المعرض:** بعد تثبيت التطبيق، اختر فيديو في المعرض ← مشاركة ← «كابشن AI» فيبدأ التفريغ مباشرة.

### النشر على GitHub Pages
1. في المستودع على GitHub: **Settings ← Pages**.
2. **Source:** Deploy from a branch، **Branch:** `main` و `/ (root)` ← **Save**.
3. بعد دقيقة أو دقيقتين يعمل الموقع على `https://اسم-حسابك.github.io/اسم-المستودع/`.
4. افتحه في Chrome على الهاتف ← ⋮ ← **تثبيت التطبيق** (لا حاجة لـ chrome://flags لأن الرابط HTTPS).

## الاستخدام على هاتف أندرويد مع خادم الحاسوب

يبقى الخادم والتفريغ على الحاسوب، والهاتف يفتح الموقع عبر شبكة الواي فاي نفسها.

1. في `server/.env` ضع `HOST=0.0.0.0` ثم أعد تشغيل الخادم. ستظهر في نافذة الخادم سطر مثل:
   `من الهاتف (نفس شبكة الواي فاي): http://192.168.1.5:5000`
2. افتح الموقع على الحاسوب واضغط زر **«على الهاتف»** أعلى الصفحة، ثم امسح رمز QR بكاميرا الهاتف.
3. إن لم تفتح الصفحة على الهاتف:
   - اسمح لـ Python في جدار حماية ويندوز (تظهر رسالة عند أول تشغيل).
   - إن كان VPN يعمل على الحاسوب ففعّل فيه «Allow LAN connections» أو أوقفه مؤقتاً.
4. **التثبيت كتطبيق بأيقونة (مرة واحدة):** متصفح Chrome لا يسمح بتثبيت التطبيقات من عنوان `http://` محلي إلا بعد السماح له:
   افتح على الهاتف `chrome://flags/#unsafely-treat-insecure-origin-as-secure`، أضف عنوان الموقع (مثل `http://192.168.1.5:5000`)، اختر **Enabled** ثم **Relaunch**.
   بعدها افتح الموقع واختر من قائمة Chrome ⋮ «تثبيت التطبيق» (أو اضغط زر «تثبيت التطبيق» أعلى الصفحة).
5. **بعد التثبيت:** من تطبيق YouTube أو Facebook اضغط «مشاركة» ← «كابشن AI»، فيُفتح التطبيق ويبدأ استخراج النص مباشرة.

> إن تغيّر عنوان الحاسوب على الشبكة (بعد إعادة تشغيل الراوتر مثلاً) فكرّر الخطوة 4 بالعنوان الجديد. لتثبيته: احجز عنواناً ثابتاً للحاسوب من إعدادات الراوتر (DHCP reservation).
> أي جهاز على شبكتك يستطيع فتح الموقع أثناء تشغيل الخادم بـ `HOST=0.0.0.0`؛ أعده إلى `127.0.0.1` إن لم تعد تحتاج الهاتف.

## إضافة خدمة تفريغ الكلام بأقل تكلفة

غيّر `STT_PROVIDER` في `server/.env`:

| المزوّد | الإعداد | التكلفة التقريبية* | ملاحظات |
|---|---|---|---|
| **Groq** (الموصى به) | `STT_PROVIDER=groq` + `GROQ_API_KEY` من [console.groq.com/keys](https://console.groq.com/keys) | ≈ 0.11$ للساعة (`whisper-large-v3`) أو ≈ 0.04$ (`whisper-large-v3-turbo`)، مع استخدام مجاني محدود يومياً | سريع جداً، ممتاز للعربية |
| OpenAI | `STT_PROVIDER=openai` + `OPENAI_API_KEY` | ≈ 0.006$ للدقيقة (≈ 0.36$ للساعة) | `whisper-1` |
| **محلي مجاني** | `STT_PROVIDER=local` ثم `pip install faster-whisper` | 0$ | يعمل دون إنترنت بعد تنزيل النموذج، أبطأ على المعالج. `small` جيد، `medium`/`large-v3` أدق للعربية |

\* الأسعار تتغيّر؛ راجع صفحة الأسعار لدى المزوّد قبل الاستخدام.

الخادم يضغط الصوت (أحادي 16kHz بمعدل 32kbps) قبل إرساله، فساعة كاملة ≈ 14 ميغابايت، أي ضمن حد 25 ميغابايت للواجهات.

## آلية الاستخراج

**من رابط** (حسب «طريقة الاستخراج»):
1. الترجمة الرسمية التي رفعها صاحب الفيديو بلغة الكلام ← الأفضل.
2. وإلا تنزيل الصوت فقط وتفريغه عبر Speech-to-Text.
3. إن لم تتوفر خدمة التفريغ أو فشلت ← الترجمة التلقائية للمنصة (بلغة الفيديو الأصلية فقط، لا ترجمة آلية) مع تنبيه بأنها أقل دقة.

يُعرض عنوان الفيديو ووصفه في بطاقة منفصلة، **ولا يُستخدمان بديلاً عن تفريغ الكلام**.

**من ملف:** يستخرج الخادم الصوت ويفرّغه، ثم يحذف الملفات المؤقتة فوراً.

## قيود المصادر

- **YouTube:** الفيديوهات العامة فقط. الخاصة أو المقيّدة بالعمر أو التي تطلب تسجيل الدخول لا تعمل.
- **Facebook / Instagram:** كثير من المحتوى يتطلب تسجيل الدخول؛ لا يتجاوز الخادم ذلك ولا يستخدم حسابك. الحل: نزّل الفيديو (إن كان لك حق ذلك) وارفعه.
- **TikTok / X / Vimeo وغيرها:** يدعمها yt-dlp للمحتوى العام، وقد تتعطل مؤقتاً عند تغيير المنصة لنظامها — حدّث المكتبة: `pip install -U yt-dlp`.
- البث المباشر الجاري وقوائم التشغيل غير مدعومة.
- استخدم الأداة مع محتوى تملكه أو يحق لك استخدامه، والتزم بشروط كل منصة.

## المشاركة

- WhatsApp وTelegram والبريد: روابط المشاركة الرسمية (`wa.me`، `t.me/share`، `mailto:`). إذا تجاوز النص الحد الآمن (≈ 3000 / 3500 / 1800 حرف) تظهر رسالة توضح ذلك مع زر نسخ النص كاملاً وزر مشاركة مقتطف.
- Facebook لا يسمح بتعبئة نص المنشور مسبقاً، لذلك يُنسخ النص وتُفتح نافذة المشاركة لتلصقه بنفسك.
- Instagram: نسخ النص للصقه يدوياً.
- على الهاتف يظهر زر «مشاركة عبر الجهاز» (Web Share API) الذي يرسل النص كاملاً لأي تطبيق.
- الموقع لا ينشر شيئاً تلقائياً على حساباتك.

## تغيير اسم الموقع

غيّر `SITE_NAME` في أعلى `script.js` (والنص داخل `<title>` في `index.html` إن أردت ظهوره قبل تحميل السكربت).

## واجهة الخادم (API)

| الطلب | الوصف |
|---|---|
| `GET /api/health` | حالة الخادم وخدمة التفريغ والحدود |
| `POST /api/transcribe/url` | `{"url", "language", "mode": "auto"\|"captions"\|"speech"}` ← `{"job_id"}` |
| `POST /api/transcribe/file` | `multipart`: `file`، `language` ← `{"job_id"}` |
| `GET /api/jobs/<id>` | `{"status": "running"\|"done"\|"error", "stage", "progress", "result", "error"}` |

النتيجة: `text` (فقرات)، `segments` (`start`/`end`/`text` بالثواني)، `has_timestamps`، `language`، `source`، `meta`، `warnings`.

## تحسينات مستقبلية مقترحة

- تقسيم المقاطع الأطول من 90 دقيقة إلى أجزاء وتفريغها بالتوازي.
- تحسين علامات الترقيم بنموذج لغوي (اختياري ومدفوع) مع الحفاظ على النص الأصلي.
- تمييز المتحدثين (Speaker diarization).
- تصدير VTT وDOCX، ومحرر يربط كل جملة بتوقيتها مع تشغيل الفيديو.
- حد لعدد الطلبات لكل مستخدم (rate limiting) قبل نشر الموقع على الإنترنت، وتشغيله عبر `gunicorn`/`waitress` بدلاً من خادم Flask التجريبي.
- الوضع الليلي.
